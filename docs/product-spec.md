# Steppie 제품 명세

> 기준 문서: `docs/planning/steppie_planning_document.md`  
> 버전: 0.1.0  
> 범위: iOS와 Android v1.0 공통 제품 요구사항.

## 1. 제품 개요

Steppie는 발달장애·자폐 스펙트럼 사용자가 하루 일과를 그림, 색상, 짧은 문구로 예측 가능하게 따라갈 수 있도록 돕는 루틴 시각화 앱이다.

핵심 가치:

- 단순함: 한 화면에 하나의 핵심 행동만 보여준다.
- 예측 가능성: 같은 동작은 항상 같은 결과를 만든다.
- 불안 감소: 다음에 할 일을 명확히 보여주고 완료 경험을 즉시 제공한다.

지원 플랫폼:

- iOS / iPadOS
- Android phone / Android tablet

v1.0 출시 언어:

- 한국어
- 영어

## 2. 사용자

### 2.1 주 사용자

| 항목 | 내용 |
|---|---|
| 대상 | 발달장애·자폐 스펙트럼 아동~성인 |
| 연령 | 만 4세 ~ 성인 |
| 특성 | 텍스트보다 시각 정보에 익숙할 수 있음, 일과의 예측 가능성이 중요함, 감각 민감성 개인차가 큼, 터치 정확도 개인차가 있음 |
| 사용 환경 | 가정, 학교, 복지관, 이동 중, 오프라인 환경 |

### 2.2 보조 사용자

| 사용자 | 역할 |
|---|---|
| 보호자 | 루틴 생성/수정, 알림 설정, 진행 상황 확인 |
| 특수교사 | 학교 루틴 설정, 학생별 맞춤 구성 |
| 치료사 | 치료 목표에 맞는 루틴 설계 |

## 3. 앱 모드

Steppie는 아이 모드와 보호자 모드를 분리한다.

```text
Steppie
├── 아이 모드
│   └── 우상단 모서리 3초 길게 누르기 + PIN 입력 -> 보호자 모드
└── 보호자 모드
    └── 완료 또는 3분 미조작 -> 아이 모드
```

공통 규칙:

- 앱 실행 후 기본 진입은 아이 모드다.
- 아이 모드에는 설정 진입 UI를 일반 버튼으로 노출하지 않는다.
- 보호자 모드 진입에는 4자리 PIN이 필요하다.
- 최초 실행 시 보호자 PIN을 생성해야 한다.
- PIN 분실 대응을 위해 6자리 복구 코드를 제공한다.
- 보호자 모드는 완료 버튼 또는 3분 미조작 시 아이 모드로 돌아간다.

## 4. v1.0 기능 범위

### 4.1 아이 모드

| ID | 기능 | 요구사항 |
|---|---|---|
| F-01 | 루틴 목록 보기 | 오늘의 일과를 카드 형태로 순서대로 표시한다. 목록은 확인용이며 완료 처리는 하지 않는다. |
| F-02 | 포커스 뷰 | 앱 실행 시 기본 화면이다. 현재 해야 할 루틴 카드 하나를 크게 표시한다. |
| F-03 | 완료 처리 | 포커스 카드 탭 1회로 현재 루틴을 완료 처리한다. |
| F-04 | 진행률 표시 | 완료 수와 전체 수를 아이가 이해할 수 있는 형태로 표시한다. 색상만으로 상태를 전달하지 않는다. |
| F-05 | 음성 안내 | 카드 진입 시 활동명을 TTS로 안내한다. 설정에서 끌 수 있어야 한다. |
| F-06 | 예고 알림 | 예정 시각이 있는 활동에 대해 보호자 설정에 따라 10분 전/5분 전 알림을 보낸다. |
| F-07 | 루틴 완료 | 모든 루틴 완료 시 전체 완료 화면과 긍정 피드백을 표시한다. |
| F-08 | 되돌리기 | 완료 직후 설정된 시간 동안 아이 모드에서도 완료를 되돌릴 수 있다. |

### 4.2 보호자 모드

| ID | 기능 | 요구사항 |
|---|---|---|
| F-10 | 루틴 생성/편집 | 활동 카드 추가, 제목 수정, 순서 변경, 삭제를 지원한다. |
| F-11 | 아이콘/이미지 설정 | 기본 아이콘 선택과 사진 촬영/갤러리 업로드를 지원한다. |
| F-12 | 색상 설정 | 카드별 배경 색상을 디자인 토큰 범위 안에서 지정한다. |
| F-13 | 시간 설정 | 활동별 예정 시각을 선택적으로 지정한다. |
| F-14 | 음성 설정 | TTS ON/OFF, 속도, 볼륨을 설정한다. 음성 종류는 플랫폼 지원 범위에서 제공한다. |
| F-15 | 피드백 설정 | 애니메이션 강도, 효과음, 햅틱/진동 ON/OFF를 설정한다. |
| F-16 | 루틴 템플릿 | 아침, 학교, 취침 루틴 템플릿을 제공한다. |
| F-17 | 진행 기록 | 날짜별 완료 현황을 확인한다. |
| F-18 | PIN 변경 | 보호자 PIN 설정 및 변경을 지원한다. |
| F-19 | 백업/복원 | 플랫폼 클라우드를 통해 백업과 replace 복원을 지원한다. |

## 5. 화면 구조

### 5.1 아이 모드 IA

```text
앱 실행
└── 포커스 뷰
     ├── 위로 스와이프 -> 루틴 목록 뷰
     │    └── 카드 탭 -> 포커스 뷰
     ├── 카드 탭 -> 완료 피드백
     │    └── 다음 카드 포커스 뷰
     └── 모든 카드 완료 -> 루틴 완료 화면
```

요구사항:

- 완료 처리는 항상 포커스 뷰에서만 가능하다.
- 루틴 목록 뷰는 순서와 상태를 확인하는 화면이다.
- 루틴 목록에서 카드를 탭하면 해당 루틴 포커스 뷰로 이동한다.
- 아이 모드에는 삭제, 설정 변경, PIN 변경 기능이 없어야 한다.

### 5.2 보호자 모드 IA

```text
보호자 모드 홈
├── 루틴 관리
│   ├── 루틴 세트 목록
│   ├── 새 루틴 세트 만들기
│   ├── 카드 편집
│   └── 템플릿에서 시작하기
├── 환경 설정
│   ├── 피드백 설정
│   └── 알림 설정
├── 진행 기록
└── 앱 설정
    ├── PIN 변경
    ├── 복구 코드 확인
    └── 백업/복원
```

요구사항:

- 보호자 모드의 destructive action은 명확한 확인을 요구한다.
- 편집 중 저장하지 않은 변경사항은 화면 이탈 시 사용자에게 알려야 한다.
- 보호자 모드에서 3분 미조작 시 아이 모드로 돌아간다.

## 6. 화면별 요구사항

### 6.1 포커스 뷰

필수 요소:

- 현재 루틴의 아이콘 또는 사진.
- 현재 루틴 제목.
- 진행률.
- 완료 가능한 큰 tap target.
- 보호자 모드 숨은 진입 영역.

동작:

- 카드 탭 1회로 완료 처리한다.
- 완료 후 피드백을 보여주고 다음 미완료 루틴으로 이동한다.
- TTS가 켜져 있으면 포커스된 루틴명을 안내한다.
- 오늘 완료할 루틴이 없으면 빈 상태 또는 전체 완료 상태를 보여준다.

### 6.2 루틴 목록 뷰

필수 요소:

- 오늘의 루틴 카드 목록.
- 각 카드의 순서, 아이콘/사진, 제목, 완료 상태.
- 포커스 뷰로 돌아가는 동작.

동작:

- 위/아래 스와이프로 포커스 뷰와 전환할 수 있다.
- 목록에서 루틴을 완료 처리하지 않는다.
- 완료 상태는 색상 외 텍스트/아이콘/접근성 값으로도 표현한다.

### 6.3 전체 완료 화면

필수 요소:

- 짧은 축하 문구.
- 완료 상태를 나타내는 시각 피드백.
- 아이 모드로 머무르는 기본 동작.

동작:

- TTS가 켜져 있으면 완료 축하 문구를 안내한다.
- Reduce Motion 또는 feedback off 설정에서는 장식성 애니메이션을 줄이거나 제거한다.

### 6.4 보호자 PIN 화면

필수 요소:

- 4자리 PIN 입력 UI.
- 큰 숫자 keypad.
- 오류 메시지 영역.

동작:

- 올바른 PIN 입력 시 보호자 모드로 진입한다.
- 잘못된 PIN 입력 시 오류를 표시하고 접근성 안내를 제공한다.
- 원본 PIN은 저장하지 않는다.

### 6.5 루틴 관리 화면

필수 요소:

- RoutineSet 목록 또는 현재 활성 RoutineSet.
- 루틴 카드 목록.
- 추가, 편집, 삭제, 순서 변경 액션.
- 템플릿에서 시작하기 액션.

동작:

- 루틴 순서는 0부터 연속된 order로 저장한다.
- 삭제는 기존 진행 기록을 깨지 않도록 처리한다.
- 저장 후 아이 모드에 즉시 반영한다.

### 6.6 카드 편집 화면

필수 요소:

- 활동 이름 입력.
- 아이콘/사진 선택.
- 색상 선택.
- 예정 시각 설정.
- 저장/취소 액션.

동작:

- 활동 이름은 최소 하나의 locale 값이 필요하다.
- 색상은 `docs/design-tokens.md`의 카드 색상 토큰 중 선택한다.
- 사진은 백업 계약에서 복원 가능한 asset reference를 가져야 한다.

### 6.7 환경 설정 화면

필수 요소:

- 피드백 강도: `strong`, `normal`, `quiet`, `off`.
- 효과음 ON/OFF.
- TTS ON/OFF, 속도, 볼륨.
- 햅틱/진동 ON/OFF.
- undo 표시 시간: 3초, 5초, 10초.
- 예고 알림: 10분 전, 5분 전, 없음.
- 방해 금지 시간.

동작:

- 설정 변경은 다음 피드백/알림부터 적용한다.
- 권한 거부 상태에서도 앱의 핵심 루틴 기능은 계속 동작해야 한다.

### 6.8 진행 기록 화면

필수 요소:

- 날짜별 완료 현황.
- 완료 수/전체 수.
- 루틴별 완료 상태.

동작:

- 로컬 날짜 기준으로 그룹화한다.
- 삭제된 루틴의 과거 기록도 이해 가능한 이름으로 표시한다.

### 6.9 백업/복원 화면

필수 요소:

- 마지막 백업 시각.
- 백업 생성 액션.
- 백업 복원 액션.
- 백업에 포함되는 정보 설명.

동작:

- 백업/복원은 보호자 모드에서만 가능하다.
- v1.0 복원은 Replace mode만 지원한다.
- 복원은 all-or-nothing으로 처리한다.
- 복원 후 알림 스케줄을 다시 만든다.

## 8. 비기능 요구사항

### 8.1 오프라인

- 핵심 루틴 기능은 100% 오프라인으로 동작해야 한다.
- 클라우드 연결 실패는 백업/복원에만 영향을 주어야 한다.

### 8.2 성능

- 앱 실행 후 아이 포커스 뷰는 지연 없이 표시되어야 한다.
- 완료 피드백은 탭 후 0.4초 이내 시작되어야 한다.
- 완료 피드백은 1.5초 이내 종료되어야 한다.

### 8.3 접근성

- `docs/accessibility-checklist.md`를 출시 기준으로 사용한다.
- VoiceOver/TalkBack, Dynamic Type/Font Scale, Reduce Motion/animation scale off를 지원한다.
- 아이 모드 touch target은 최소 80x80 pt/dp-equivalent다.

### 8.4 개인정보

- 원본 PIN과 원본 복구 코드는 저장하지 않는다.
- 백업에는 원본 PIN, 원본 복구 코드, analytics identifier를 포함하지 않는다.
- v1.0에는 광고와 인앱결제가 없다.

## 10. v1.0 제외 범위

다음 항목은 v1.0 필수 범위가 아니다.

- 서버 기반 계정 시스템.
- 보호자 간 실시간 동기화.
- Merge restore.
- AI 기반 루틴 추천.
- 일본어 등 추가 언어.

## 11. 완료 기준

v1.0 기능은 다음 조건을 만족해야 완료로 본다.

- 제품 명세의 해당 기능 요구사항을 충족한다.
- 관련 공통 계약 문서와 충돌하지 않는다.
- iOS와 Android에서 사용자 경험 의미가 동일하다.
- 관련 테스트 시나리오를 통과한다.
- 접근성 필수 항목을 통과한다.
